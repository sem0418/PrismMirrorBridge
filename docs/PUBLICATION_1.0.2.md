# v1.0.2 发布记录

用户已在 Windows 环境实测确认 1.0.2 可正常使用，并于 2026-11-08 授权发布到个人仓库。正式支持平台及发行件均为 Windows x64。

正式发布整理更新文档、发布记录、匿名诊断时间戳，并将 CI 收敛为 Windows。`src`、`data`、`cli.mjs`、默认配置、包版本及 Windows 操作脚本均与用户确认的测试包逐文件比较；不把发布整理当作新的功能修复。

## 验证范围

- Windows 用户实机：已确认本版本可正常使用；维护环境没有远程访问用户电脑。
- Linux 维护环境：70 项离线测试，CLI 接入/修复/撤销，以及从干净目录解压后的检查。
- 官方 Prism 11.1.1 Linux 可执行文件：受控响应下验证 NeoForge 组件校验状态问题和正式文件落盘；不等同于完整 ATM10 导入。
- 用户反馈与维护环境托管检查分别记录；托管 CI 不能代替所有桌面交互或游戏场景。
- 正式 CI 仅运行 Windows。历史其他系统诊断资料保留为故障研究证据，不构成支持承诺。

发布检查的机器可读记录位于 `test-results/publication-1.0.2.json`。旧报告中的暂停上传字段记录当时状态，不表示当前仍在等待授权。

## 第三方服务

仅发布本机工具和源码，不部署公共转发服务，不代用户向第三方发送登记评论。MCIM 的接入登记与本地转接方式仍需维护者按其规则确认；仓库公开不代表已获得镜像服务方认可或授权。
