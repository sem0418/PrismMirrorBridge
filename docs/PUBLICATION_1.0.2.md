# v1.0.2 发布记录

用户已复测反馈 1.0.2 可用，并于 2026-11-08 授权发布到个人仓库。

正式发布整理只更新文档、发布记录和匿名诊断时间戳。`src`、`data`、`cli.mjs`、默认配置、包版本及 Windows 操作脚本均与用户确认的测试包逐文件比较；不把发布整理当作新的功能修复。

## 验证范围

- 用户反馈：此版本已可用；没有收集新的实机日志或完整进入游戏验收记录。
- Linux 维护环境：70 项离线测试，CLI 接入/修复/撤销，以及从干净目录解压后的检查。
- 官方 Prism 11.1.1 Linux 可执行文件：受控响应下验证 NeoForge 组件校验状态问题和正式文件落盘；不等同于完整 ATM10 导入。
- 真实 Windows + Prism 的完整导入、证书交互和游戏启动仍未由维护环境实机复测。
- 托管 CI 的结果应按对应提交、操作系统及实际通过/跳过数量读取，不替代 Windows 桌面验收。

发布检查的机器可读记录位于 `test-results/publication-1.0.2.json`。旧报告中的暂停上传字段记录当时状态，不表示当前仍在等待授权。

## 第三方服务

仅发布本机工具和源码，不部署公共转发服务，不代用户向第三方发送登记评论。MCIM 的接入登记与本地转接方式仍需维护者按其规则确认；仓库公开不代表已获得镜像服务方认可或授权。
