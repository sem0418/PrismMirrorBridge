# 新设备启动 501 的定位与验证

这是 1.0.3 候选的维护环境记录。没有访问用户电脑或读取其本机日志；用户报告的具体 URL 未提供，因此不能证明其故障一定与本报告完全相同。

## 已复现的原因

在 Windows 10.0.26100 x64 托管虚拟机运行官方 Prism 11.1.1，使用全新 Prism 数据目录、全新桥接器缓存及默认关闭的兼容配方。Minecraft 和 LWJGL 元数据均为 200，随后 Prism 对 `net.minecraft.java/index.json` 连续三次收到 501。这与用户描述的“游戏数据完成后、启动时仍需元数据”顺序一致。

原实现未提供 BMCL → Prism 的 Java 元数据转换。Prism 的 `AutoInstallJava` 在未找到其需要的运行时时，会读取 `net.minecraft.java`。已有 Java 路径或已安装运行时的设备可能跳过该路径；旧设备试用成功不能覆盖新设备。

原始 Windows 复现：[运行记录](https://github.com/sem0418/PrismMirrorBridge/actions/runs/42481952687)，对应 `test-results/windows-501-reproduction-1.0.2.json`。

另一个可复现的 501 路径是普通 LWJGL 3.3.3 在 Minecraft 组件尚未解析时被请求。新增来自 BMCL Minecraft 1.21.1 的预置别名，并核对实际核心库版本，不依赖并行请求的完成先后。未知组件继续明确失败。

## 转换和完整性校验

Windows x64 的 Mojang Java 索引及组件直接由 BMCL Java 总清单转换。保留运行时名字、操作系统、Java 版本、下载类型及原始清单 SHA1。没有启用 Prism 官方配方，也没有关闭 TLS 或文件校验。

真实 Java 21 清单的 JSON 内容相同，但 BMCL 将 Mojang 的带分隔空格表示压缩成紧凑 JSON：

| 响应 | 字节数 | SHA1 |
| --- | ---: | --- |
| Mojang 原清单 | 148529 | `cb4394a27089d19f65d5baa6cf0482c27c3c7865` |
| BMCL 紧凑表示 | 141748 | `7a85617052e892b9d2d2b02ed29c8d5e32a73027` |

因此不能把紧凑响应配上原哈希直接交给 Prism。候选实现恢复原始序列化，只有恢复后的字节长度和 SHA1 都与 Mojang 公布值一致，才缓存并提供给 Prism。任何不匹配均返回错误。清单原字节通过本地按哈希寻址的接口提供，跨桥接器重启可复用；损坏缓存被拒绝。

Java 二进制文件仍从 BMCL 下载，并按清单 SHA1 校验。Windows 实测发现清单的 402 个文件条目只对应 197 个不同下载地址；三份许可证各重复 69 次，批量请求收到 429，而之后单次对照为 200。现仅对已验证清单登记且不大于 1 MiB 的小文件合并请求并缓存；大文件继续流式传输，Range/HEAD 仍走原有路径。上游失败或文件校验失败不会产生成功响应。

## 验证

- Linux：85 项自动化回归、CLI 生命周期、32 项真实联网检查通过；Java 8/16/17/21/25 的清单恢复及原始 Prism 解析器检查通过。
- Linux 官方 Prism 11.1.1：空目录开始的下载实验在测试预算中断后，只复用本实验自己的下载继续；共核对 3888 个资源、资源索引、客户端 JAR 和 57 个库 JAR 的 SHA1。曾观察到 116 次临时镜像错误，重试后下载完成。最终代码复启并目视确认 Minecraft 1.21.1 Demo 主菜单，桥接器错误为 0。没有使用账号或修改认证逻辑，使用的是启动器自带试玩流程。
- Windows 官方 Prism 11.1.1：全新 Prism 及桥接器缓存，保持正式默认重试/超时参数。自动安装 Java 的 402 个文件全部独立校验 SHA1，并实际执行下载得到的 `java.exe -version`，输出 OpenJDK 21.0.7，退出码 0。桥接器错误数为 0，205 次重复小文件请求复用缓存。
- Windows CI：85 项中 83 通过、2 项历史 POSIX 专用检查跳过、0 失败。[实际运行](https://github.com/sem0418/PrismMirrorBridge/actions/runs/42485444928)；完整结构化结果见 `test-results/windows-java-1.0.3.json`。

Windows CI 使用其自有、可销毁的管理员虚拟机证书库临时信任测试 CA，完成后移除，TLS 校验持续启用。它没有验收普通用户首次接入时的证书确认对话框。Linux 图形实验只为验证核心，不构成 Linux 发行版支持。

## 验证边界及用户操作

**用户新设备、真实账号登录、Windows 完整 ATM10 导入并进入游戏：未实机验证。** 本次 Windows 结果只证明官方 Prism 完整自动安装所需 Java 并执行该 Java；Linux 结果是原版试玩启动，不是 ATM10 完整启动。

从零重装时：退出 Prism 和工具，在旧工具运行 `03-undo.cmd`，再删除旧工具目录；解压候选包，运行 `01-setup.cmd` 选择同一份 `prismlauncher.cfg`，运行 `02-start.cmd` 后重新打开 Prism。保留 Prism 数据，不必复制旧配置或 `.bridge`。直接覆盖原工具而保留接入时，应退出 Prism 后运行 `05-repair-metadata.cmd`，避免旧元数据哈希状态混入。

镜像可达性、网络速度和限流仍取决于使用时的网络与上游；遇到错误继续明确失败，不伪造元数据、不回退伪装成功。其他 Java 供应商仍可能需要已有 Java 或用户显式启用兼容配方。若 501 中的组件不是本报告列出的项目，需依据该请求 URL 继续定位。
